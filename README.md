## Essa pasta de códigos é sobre o assunto de comandos de repetição e o uso do "while"
#Primeiro código de exemplo:
Imprimindo todos os números inteiros de 1 até 100.
- i = 1
- while (i <= 100):
- print(i)
- i = i + 1
- print(" Fim do programa!")

#Segundo código de exemplo:
Imprimindo todos os números inteiros de 1 até n.
- n = int( input(" Digite um número inteiro positivo: "))
- i = 1
- while i <= n:
- print(i)
- i = i + 1
- print(" Fim do programa!")

#Terceiro código de exemplo:
Contagem regressiva (com entrada):
- n = int( input(" Digite um número inteiro positivo: "))
- while n >= 0:
- print(n)
- n = n - 1
- print("BOOM!")
